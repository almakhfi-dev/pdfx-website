Guidelines for Reporting Issues

To help us diagnose and resolve technical issues quickly, please include the following details in your message:

  • Tool Name: The specific tool you were using (e.g., JPG to PDF, Merge PDF, Split PDF).
  • Browser & Operating System: Your browser name and version (e.g., Chrome 120 on Windows 11, Safari on iOS).
  • Description of Behavior: What happened versus what you expected to happen.
  • Error Messages: Any error message text displayed in the tool status area or browser console.

Privacy Reminder

Please do not attach confidential documents, private passwords, or sensitive personal data to your support email. Describe the issue in general terms so we can safely troubleshoot the behavior.
