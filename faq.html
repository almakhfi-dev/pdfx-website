PDFx FAQ

Answers about supported files, downloads, and processing documents in your browser.

Where is the result?

Check your browser’s Downloads list. PDF page editing and image-to-PDF export a PDF. PDF to JPG downloads a ZIP containing the JPGs, named by source page number.

Can I process a large scan?

Available browser memory and page dimensions matter. If the operation stalls, try a smaller source or convert fewer pages in one pass. Keep the original file until the output is verified.

What if a PDF is protected or damaged?

Check whether it opens in a local viewer. For a password-protected document, use an authorized unlocked copy. For an unreadable file, export a fresh copy from its source.

Where does PDFx process files?

The tool code runs document operations in the browser. The site loads resources from hosting, library and ad providers. See the Privacy Policy for the distinction.
