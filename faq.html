Frequently Asked Questions

What is PDFx?

PDFx is a collection of online tools for common PDF and image processing tasks.

Is PDFx free to use?

The PDFx website provides free access to its available online PDF tools.

Can I convert JPG or PNG images to PDF?

Yes. The JPG / PNG to PDF tool allows you to select multiple images, change their order, rotate pages and create a PDF.

Can I convert PDF pages to JPG?

Yes. You can select the PDF pages you want to convert and create JPG images from those pages.

Can I merge multiple PDF files?

Yes. The Merge PDF tool combines multiple PDF files into a single PDF document.

Can I delete PDF pages?

Yes. The Delete PDF Pages tool allows you to select pages that you want to remove from a PDF.

Can I rearrange PDF pages?

Yes. The Rearrange PDF tool allows you to change the order of pages before creating the updated PDF.

What is PDF Extend?

PDF Extend allows you to add new JPG or PNG pages to an existing PDF and change the order of the pages.

Are my files uploaded to a server?

Supported browser-based PDFx tools are designed to process files locally in your browser whenever possible. The exact behavior can depend on the tool and your browser.

Does PDFx have an Android app?

Yes. PDFx is also available as an Android application.
