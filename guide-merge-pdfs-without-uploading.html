Merge multiple PDF files without uploading them

A report, a receipts file and an appendix need to arrive as a single attachment. Name the inputs clearly so you can tell them apart in the preview.

Steps in PDFx

Open Merge PDF

  1. Open Merge PDF and select all three PDFs in the same file picker. Number copies of the filenames if your picker sorts by name.
  2. Compare the list with your intended order. If it is wrong, reopen the picker and select the full batch again.
  3. Choose Merge PDFs, open the download, and check the first page of every section.

Before you share the output

Keep signed originals if you need to verify signatures. Merging copies pages into a newly generated PDF, so check document-level features separately.
