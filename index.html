How PDFx works

Choose a tool and select your local files. Preview or select pages where the tool offers that option, run the operation and open the downloaded copy to check it. You can use the tools without installing software or creating an account.

What you can do with PDFx

  • Students can combine photos of handwritten homework into one submission.
  • Teachers can extract the answer sheet from a longer lesson packet.
  • Office staff can merge a report and appendices in delivery order.
  • Freelancers can add a photographed signature page to a project handoff.
  • Small businesses can export selected catalog pages as images.
  • Anyone sorting scans can reorder pages and correct sideways scans.

File privacy

The tools read and generate documents in your browser. The site still loads processing libraries and advertising scripts over the network. Large scans can strain device memory. Read the Privacy Policy for details.

Common questions

Where is my download?

Check your browser’s download history or your Downloads folder. The PDF to JPG tool delivers images in a ZIP archive.

Why did my file fail to open?

Confirm that it opens in a local viewer and that the format matches the tool. For protected files, use an authorized unlocked copy.
