How to Merge PDF Files Step by Step

Combining disparate document pages into a consolidated report is simple with PDFx:

1

Select PDF Files

Click "Choose Files" and pick two or more PDF files you want to combine into one.

2

Verify Document List

Review the loaded file list and page counts displayed on screen to make sure all necessary parts are included.

3

Download Merged PDF

Click “Merge PDFs” to create and download a single file.

Formats and troubleshooting

Combine a report and its appendices for delivery.

Files are copied in the order shown in the file list. If that order is wrong, reopen the picker and select the full batch again. Numbering copies of the filenames can help when the picker sorts by name. Check forms, bookmarks and signatures in the exported copy.
