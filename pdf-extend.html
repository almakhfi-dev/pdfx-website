Add Pages to an Existing PDF

PDFx allows you to add new JPG or PNG pages to an existing PDF document. You can then organize the pages before creating the extended PDF.

This can be useful when you need to add scanned pages, photos, receipts, forms or other image-based pages to an existing PDF.

How to Extend a PDF

1. Open the PDFx PDF Extend tool.

2. Select the existing PDF.

3. Add JPG or PNG pages.

4. Arrange the pages into the desired order.

5. Click "Extend PDF".

Why Add Pages to a PDF?

Adding pages can help keep related information in one document instead of maintaining several separate files.
