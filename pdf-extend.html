Add Pages to an Existing PDF

PDFx PDF Extend lets you add JPG and PNG images as new pages to an existing PDF document.

This can be useful when you want to add scanned pages, photos or additional document pages to an existing PDF.

How to Extend a PDF

1. Open the PDF Extend tool.

2. Select an existing PDF file.

3. Click "Add JPG / PNG Pages".

4. Select the images you want to add.

5. Arrange the pages in your preferred order.

6. Click "Extend PDF".
